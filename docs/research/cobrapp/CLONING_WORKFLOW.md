Se aplica su habilidad clone-website para inspección, medición, archivos por origen y comparación visual. La implementación se integra en el proyecto React/Next existente para conservar el backend probado de UniRide. No se presentan las cifras ni los productos de cobranza de la referencia como datos de UniRide.

## Rutas

| Referencia | UniRide |
|---|---|
| / | / |
| /blog | /blog |
| /blog/categoria/* | /blog/categoria/* |
| /blog/* | /blog/* |
| /planes | /planes |
| /contacto | /contacto |
| /nosotros | /proyecto |
| /descargas | /descargas |

Fuentes: portadas y estados observados de cobrapp.co; artículos originales del Blogger del equipo. La guía visual conserva Archivo, paleta verde/menta/papel, cuadrícula, tarjetas con cinta, recibo, menú, tema, escenas fijadas y carrusel.

## Verificación

La réplica de UniRide requiere su propia compilación y revisión de todas las páginas: que la plantilla pase sus pruebas no valida automáticamente la aplicación modificada.
